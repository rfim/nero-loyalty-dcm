No duplicate transaction, event or customer IDs; every foreign key (store, customer) resolves; every redeem event has a reward_id and no other event type does; no negative baskets or item counts in the validated silver tables.

Queried live from NERO_DB."01_SILVER" — the same validated tables published by the contract-validation pipeline from stores.csv, loyalty_customers.csv, transactions.csv and loyalty_events.csv. Tier is each customer's current tier as recorded today, not their historical tier at the time of each visit — the source data has no tier-change history (old/new tier) to reconstruct that precisely, so treat the loyalty/sales comparison above as directional, not exact.
